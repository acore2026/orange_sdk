Agent SDK · MASQUE CONNECT-IP 透明三层架构

上图表达物理承载，下图表达 A → 5GC → B 的内层 IP 数据路径。交换机到服务器是一条链路，进入服务器后按 MASQUE 目的端口 A/B 分流到两个 AgentRuntime；服务器侧系统均不属于 SDK 交付范围。

端侧初始化

  • • 创建 Agent TUN / Android VpnService
  • • 只给对端 Agent 地址安装精确路由
  • • Android 必须 protect QUIC Socket
  • • TUN MTU 默认 1280，可由部署调整

CONNECT-IP 约束

  • • 扩展 CONNECT 的 :protocol = connect-ip
  • • Capsule-Protocol = ?1
  • • HTTP Datagram Context ID = 0
  • • 标准：RFC 9484 / RFC 9297

外部系统对接

  • • 部署方只向端侧提供 URL 与可选鉴权值
  • • AgentRuntime 返回本 UE 的 PDU IPv4
  • • 端到端结果证明业务包经过 5GC 用户面
  • • 服务器内部实现不属于 SDK 交付范围
